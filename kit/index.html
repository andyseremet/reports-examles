Topic cards for other apps

Each topic in the property check can be used on its own: one card with one line of HTML, or a small app of your own. The cards come plain, so your app styles them; this page shows one way. The same rules apply as in the app: data that could not be checked is never shown as good news.

One card, one line

Load the kit once, then add a tag for each topic. Tags for the same place share their data.

<script type="module" src="https://andyseremet.github.io/reports-examles/kit/v1/js/kit.js"></script>
<plc-topic topic="radon" postcode="S70 2TA"></plc-topic>

A small app: flood check

The same topics in code: a flood-only check for any postcode, with three of the app's topics.

import { checkPlace } from "https://andyseremet.github.io/reports-examles/kit/v1/js/kit.js";
checkPlace({ postcode }, { topics: ["flood", "surfacewater", "pastfloods"],
  onCard: (topic, result, html) => { /* show html */ } });

Topics you can use
